# v0.2.0 — RK3588 离线语音助手

本版提供 Orange Pi 5 / RK3588S 上的 C++17 离线语音助手源码、固定环境与资产准备说明，以及公开性能快照。安装时需要另行获取模型与推理库。

## 功能

- 本地 ASR → LLM → TTS 对话，蓝牙耳机双向录放。
- “你好小派”唤醒、15 秒连续对话窗口和播报中插话。
- 取消、清空会话、旧回答隔离、耳机断线恢复。
- 用户级服务、本地版本部署、回退和进程异常恢复。

## 支持组合

| 部分 | 固定组合 |
|---|---|
| 板卡与架构 | Orange Pi 5 / RK3588S，Linux aarch64 |
| 系统与内核 | Ubuntu 22.04.5，6.1.99-rockchip-rk3588 |
| NPU 驱动与运行库 | RKNPU 0.9.8；RKNN Runtime 2.3.2；RKLLM Runtime 1.3.0 |
| CPU 语音运行库 | Sherpa-ONNX 1.12.14；ONNX Runtime 1.17.1-patched |
| 音频 | PipeWire/PulseAudio 兼容接口；16 kHz、单声道、20 ms 帧；已公开耳机样例为 vivo TWS 4 / mSBC |

模型和库的精确来源、修订及文件哈希以本标签中的 [模型清单](https://github.com/jzh03/rk3588_voice_engine/blob/v0.2.0/models/manifest.json) 和 [依赖清单](https://github.com/jzh03/rk3588_voice_engine/blob/v0.2.0/deps/manifest.json) 为准。其他板卡、系统、内核与 SDK 组合需要另行适配和验证。

## 公开结果及其边界

[性能快照](https://github.com/jzh03/rk3588_voice_engine/blob/v0.2.0/docs/performance-snapshot.md) 对应 2026-10-27 的本地部署 ID `p7-m2-20261027-r2`。该 ID 标识板端已安装产物，项目版本 `v0.2.0` 标识本次源码发布，两者用途不同。

- 虚拟音频端点连续对话：10/10 轮完成。
- 真实耳机重连：空闲、录音、播放各 1 次，3/3 项完成。
- 三条重连后回答的软件响应时间：2.276 / 2.717 / 2.209 秒。

计时起点为 ASR 最终结果，终点为首帧 PCM 被音频后端接受，不包含完整声学链路。三个样例使用同一短问题，不能用于推断识别准确率、P95 延迟或长时间稳定性。可在源码根目录运行：

```bash
python3 scripts/verify_performance_snapshot.py
```

此命令仅复算公开 JSON，不执行模型推理。此次环境、安装、许可证和版本资料整理没有重新开展模型或耳机验收，也没有完成第二台空白系统的安装验收。

## 已知限制

- 默认构建不启用完整模型链路；实时使用必须准备资产并打开 ASR、TTS、LLM 三个构建开关。
- 唤醒后按当前使用说明停约 2 秒再提问；服务按需手动启停。
- 运行库及模型使用固定版本，TTS 取消实现依赖固定 ONNX Runtime API；升级需要重新验证。
- 源码包不附带模型、推理运行库、操作系统镜像或本机音频配置。资产准备说明中的来源、工具链和校验要求仍需满足。
- 本版没有对其他板卡、其他耳机、开机自启、无桌面登录或长时间无人值守作出验证承诺。
- 本地回退恢复程序、配置和资产组合，不回退操作系统、内核或驱动。

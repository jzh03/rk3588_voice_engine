# v0.3.0 — 新增百炼云端语音链路

RK3588 语音引擎新增阿里云百炼后端。双后端构建保留端侧离线模式，两档使用同一个板端用户服务。只需要云端模式时，也可单独构建云端版本。

## 功能

- 百炼流式 ASR 在录音期间通过 WebSocket 上传音频，由板端 VAD 判定说完。
- LLM 通过 SSE 增量返回文本。流式 TTS 的音频分块到达后直接进入播放队列。
- 唤醒、VAD、耳机录放和播报中插话由板端负责。续问从新采集开始，识别结果为空时可在当前对话窗口内重说。
- 双后端部署支持停服后切换运行档，两档可共用一份语速配置。

## 下载和安装

下载项目上传的 `rk3588_voice_engine-0.3.0-source.tar.gz` 与 `SHA256SUMS`，放在同一目录。运行 `sha256sum -c SHA256SUMS` 校验项目上传的源码包。

- 板卡、系统和通用依赖见[支持平台与系统依赖](https://github.com/jzh03/rk3588_voice_engine/blob/v0.3.0/docs/supported-platform.md)。
- 云端和双后端构建需要按所选运行档准备板端资产。使用百炼还需要联网，并配置自己的工作空间 ID 和 API Key。具体步骤见[云端语音指南](https://github.com/jzh03/rk3588_voice_engine/blob/v0.3.0/docs/cloud-voice.md)。
- 仅使用端侧模式时，按[资产获取与首次运行](https://github.com/jzh03/rk3588_voice_engine/blob/v0.3.0/docs/assets-setup.md)和[构建与运行](https://github.com/jzh03/rk3588_voice_engine/blob/v0.3.0/docs/build-and-run.md)准备和部署。
